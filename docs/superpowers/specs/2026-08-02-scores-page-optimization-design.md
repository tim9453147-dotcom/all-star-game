# 積分管理頁面視覺與互動優化設計文件 (Design Spec)

## 1. 概述 (Overview)
優化管理後台的「積分管理」頁面 (`app/pages/admin/scores.vue`)，移除冗餘標題與說明文字，簡化發放表單結構，並將紀錄表格與搜尋篩選區塊改為現代精緻的深色透明感 (Glassmorphism) UI 畫面。

---

## 2. 核心變更與優化項目 (Key Changes & Improvements)

### 2.1 表單精簡與 redundancy 消除
- **移除重複標題**：移除展開表單內部的 `<h3 class="text-amber-300">發放積分</h3>` 標題（因為頂部 Header 已有 `+ 發放積分` / `收起表單` 按鈕）。
- **簡化積分預覽區塊**：移除原本獨立且佔據空間的「積分加總」外框，改將選擇任務後獲得的積分點數以動態亮黃色膠囊標籤 (`+XX 分`) 整合在選單右側或確認按鈕旁。
- **欄位精簡與對齊**：
  - 玩家下拉選單 (Player Select)
  - 任務下拉選單 (Task Select)
  - 備註輸入框 (Note Input)
  - 確認發放按鈕 (Submit Button) + 點數預覽膠囊

### 2.2 搜尋與篩選列 (Filter Toolbar)
- 整合「玩家篩選下拉選單」與「關鍵字搜尋框」至單一條列式工具列中。
- 當有套用篩選或搜尋時，顯示「重設篩選」快捷按鈕與比對結果筆數。

### 2.3 紀錄列表與手持裝置卡片 (Table & Mobile Cards)
- **桌面版表格 (Desktop Table)**：
  - 欄位：`發放時間`、`玩家資訊` (遊戲 ID + 姓名)、`任務名稱`、`發放積分` (亮黃點數膠囊)、`備註`、`操作`。
  - 新增 Hover 亮色漸層與平滑過渡動畫。
  - 編輯狀態：精簡輸入框與儲存/取消按鈕樣式。
- **行動版卡片 (Mobile Cards)**：
  - 圓角卡片與精緻邊框，右上角呈現高亮積分膠囊，底部為細緻時間與編輯按鈕。
- **空狀態 (Empty State)**：
  - 採用圖示與簡潔無資料提示文字。
